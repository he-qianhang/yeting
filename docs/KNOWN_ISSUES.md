# 已知问题与支持范围

- **YouTube 实际线路问题未解决。** 代码包含匿名准备和本地验证流程；历史样本或本地单元测试不保证当前用户网络可用。本次开源没有重新测试或修复线路。
- 抖音、B站等来源平台也可能变更页面和访问条件。普通样本成功不等于支持全部链接、会员、付费、地区限制内容或播放列表。
- 当前 APK 构建仅包含 arm64-v8a，最低 Android8。没有证明所有 Android 版本、16KB 内存页设备和厂商后台策略都兼容。
- 小米14 / HyperOS 的自然长听、系统清理、物理触感、来电耳机和 TalkBack 仍需真机验证。模拟器通过不保证手机永不结束进程。
- 旧版倍速缺陷若已把全局速度误存为1.5，需要用户关闭“仅当前条目”后手动恢复想要的全局速度；程序不能判断旧值是否为用户主动设置。
- 平稳音量默认关闭；分析完成前播放原声，仍保留原片起伏。极低电平或提升封顶的录音不能保证完全同样响。自动语速尚未实现，手动倍速继续可用。
- 原生依赖对应源码与构建资料尚未核清，因此本项目暂不提供预编译 APK；见 [BINARY_RELEASE.md](BINARY_RELEASE.md)。

遇到后台异常，可重新打开后尽快在设置中复制播放诊断，检查并脱敏后报告。请提供版本、系统、可复现步骤及预期与实际行为，不附账号会话或私人媒体。
