# 隐私与权限

夜听 0.3.2 的收藏、音频、队列、进度、外观和睡眠设置保存在应用私有目录。Manifest 关闭 Android 系统备份。卸载、清空数据或设备丢失可能造成数据丢失。

准备内容会向原平台或其媒体服务器发送来源链接、网络请求和必要会话，第三方可能获得 IP 地址等正常联网信息；本地存储不表示完全离线运行。已准备好的音频可离线播放。

平稳音量分析和播放处理在手机本地进行，只保存小型可重建分析参数，不上传音频，也不生成整条处理后音频副本。原音频保留。

应用没有自建内容准备服务器、广告 SDK、运行时模型调用或自动上传的诊断入口。播放诊断和来源诊断在本地生成，用户可主动复制。分享前请检查条目标题、设备或网络信息，移除个人数据；不要在公开 Issue 中粘贴 Cookie、凭据或私人内容链接。

来源网页登录状态由本 App 的 WebView/CookieManager 保存；不会读取电脑浏览器会话。准备过程中，必要的本 App 来源 Cookie 可能临时写入私有缓存文件，交给本机提取组件使用，调用结束清理。没有在源码中附带账号、Cookie 或维护者密钥。

源码保留的 YouTube 本地验证流程将临时凭据放在内存，失败时停止；Google 嵌入式网页登录不可用，应用不提供该登录入口。能力与已知问题见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。

| 权限 | 用途 |
| --- | --- |
| INTERNET / ACCESS_NETWORK_STATE | 获取来源信息和音频，识别网络变化 |
| FOREGROUND_SERVICE / MEDIA_PLAYBACK | 后台播放及媒体会话 |
| FOREGROUND_SERVICE_DATA_SYNC | 后台准备任务，以及较旧Android版本上的本地音量分析 |
| FOREGROUND_SERVICE_MEDIA_PROCESSING | Android15起的本地音量分析前台服务 |
| WAKE_LOCK | 必要时维持准备和播放 |
| POST_NOTIFICATIONS | Android13 起的播放和准备通知 |

剪贴板自动识别由应用设置控制，识别后由用户确认收藏。原视频通过外部平台打开，受该平台隐私政策约束。上述说明对应本仓库当前0.3.2源码。
